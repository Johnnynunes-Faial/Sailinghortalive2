v0.16.1 — REMOVER DISPOSITIVOS DESCONHECIDOS

1. Atualizar primeiro o PC para:
   Traccar-Unknown-Devices-Monitor-v2.1.zip

2. Executar instalar-monitor-traccar.bat como Administrador.
   A chave existente é preservada.

3. Publicar esta v0.16.1 do site como habitual.

4. No Admin:
   Monitor Traccar → Dispositivos desconhecidos → Atualizar lista

5. Cada dispositivo passa a ter:
   - Copiar ID
   - Remover da lista

A remoção limpa apenas JSON/CSV do monitor.
Se o dispositivo voltar a transmitir ainda desconhecido, reaparece.

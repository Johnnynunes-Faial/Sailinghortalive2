v0.16 — MONITOR LOCAL DE DISPOSITIVOS DESCONHECIDOS

FAZER UMA VEZ ANTES/DEPOIS DO DEPLOY

A) PC DO TRACCAR
1. Extrair Traccar-Unknown-Devices-Monitor-v2.zip.
2. Executar instalar-monitor-traccar.bat como Administrador.
3. Copiar a chave mostrada no fim.
   Também fica em:
   C:\ProgramData\TraccarUnknownMonitor\monitor-key.txt

B) CLOUDFLARE TUNNEL
No tunnel que já aponta para o PC:
1. Adicionar Public Hostname.
2. Subdomain: monitor
3. Domain: sailinghortalive.com
4. Type: HTTP
5. URL: localhost:8765
6. Guardar.

C) WORKER
Adicionar Secret:
UNKNOWN_MONITOR_KEY
com a chave copiada do PC.

O wrangler.jsonc já contém:
UNKNOWN_MONITOR_URL=https://monitor.sailinghortalive.com/unknown-devices

D) SITE
Carregar esta v0.16 no GitHub como habitual.
